ESP32 web server

Objective: switch the ESP32's onboard LED on and off from a browser over a local Wi-Fi network.

Context

This is the starting point of the week. Before using the cloud, the ESP32 itself is made to act as a small web server that answers requests from a browser.

Core concepts

Web server

The ESP32 joins Wi-Fi, gets a local IP address and listens for HTTP requests on port 80.

HTTP routes

Each URL (/, /on, /off) is tied to a function that runs when the browser requests it.

Built-in LED

The board's onboard LED needs no extra wiring, so the task isolates the networking part.

System architecture

Browser → HTTP request → ESP32 web server → GPIO → LED

Setup

  1. Install the Arduino IDE.
  2. In File → Preferences, add the Espressif ESP32 board package URL to Additional Boards Manager URLs.
  3. In Boards Manager, install esp32 by Espressif Systems.
  4. Select your ESP32 board and its COM port under Tools.

Implementation

Full sketch
#include <WiFi.h>
#include <WebServer.h>

const char* ssid = "YOUR_WIFI_NAME";
const char* password = "YOUR_WIFI_PASSWORD";
WebServer server(80);

const char* page =
  "<h1>ESP32 LED Control</h1>"
  "<a href='/on'>LED ON</a> <a href='/off'>LED OFF</a>";

void handleRoot() { server.send(200, "text/html", page); }
void handleOn()   { digitalWrite(LED_BUILTIN, HIGH); server.send(200, "text/html", page); }
void handleOff()  { digitalWrite(LED_BUILTIN, LOW);  server.send(200, "text/html", page); }

void setup() {
  Serial.begin(115200);
  pinMode(LED_BUILTIN, OUTPUT);
  digitalWrite(LED_BUILTIN, LOW);

  WiFi.begin(ssid, password);
  Serial.print("Connecting");
  while (WiFi.status() != WL_CONNECTED) { delay(500); Serial.print("."); }
  Serial.println();
  Serial.print("ESP32 IP: ");
  Serial.println(WiFi.localIP());

  server.on("/", handleRoot);
  server.on("/on", handleOn);
  server.on("/off", handleOff);
  server.begin();
}

void loop() { server.handleClient(); }

How the code works

  1. WiFi.begin() connects to the network and WiFi.localIP() prints the address to open.
  2. server.on() links each URL to a handler function.
  3. Each handler sets the LED pin with digitalWrite() and returns the page.
  4. server.handleClient() in loop() checks for new browser requests.

Command flow

Click LED ON → GET /on → handleOn() → pin HIGH → LED on

Testing

  1. Upload the sketch and open the Serial Monitor at 115200 baud.
  2. Note the IP address once Wi-Fi connects.
  3. Open that IP in a browser on the same network.
  4. Press LED ON and LED OFF and watch the board.

Things to check if it doesn't work

  • The browser and ESP32 must be on the same network, and the network must be 2.4 GHz.
  • The onboard LED pin differs between board variants, which is why LED_BUILTIN is used.
